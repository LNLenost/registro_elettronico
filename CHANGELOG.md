# Changelog

## 1.0.0

Release candidate for Google Play distribution.

### Included

- Configurable home screen and bottom navigation.
- Themes and color picker.
- Local notifications for grades, notices, notes, absences and report cards.
- Historical documents separated from report cards.
- Android widgets for agenda, grades and timetable.
- Protected session-token storage with migration from legacy profiles.
- Redacted diagnostic logging and error reports.

### Deliberately not included

- Absence-justification REST operations.
- Noticeboard responses.
- Homework uploads and teacher-message operations.
- Parent-teacher meetings, help desk and recovery workflows.
- iOS widgets.

These features require a separately verified API contract or an available native build/test environment.
